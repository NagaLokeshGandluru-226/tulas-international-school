# Tulas International School — Premium React Redesign

A redesigned responsive school website concept using React, Vite, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed in the terminal (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Notes before publishing

- The page has a new editorial visual direction with a forest-green, ivory, and muted-gold palette.
- School highlights and contact details should be confirmed against the school's current official information before publication.
- Images are illustrative remote Unsplash photos, not verified photos of the Tulas campus. Replace them with approved school images for a faithful official site.
- The admissions form is a front-end demo. It validates inputs and displays a confirmation, but it does not transmit or store information.
- Social URLs are generic placeholders and should be replaced with verified official profiles.


## Official school imagery
The hero and campus/story photos now reference image assets hosted on the official Tulas International School website (`tis.edu.in`): archery, pottery, dance/art, and swimming. These load from the school's server while online. If the school changes or removes those asset URLs, download approved image files and update the `src`/CSS references. Please confirm permission for reuse before public deployment.
